# DrawPort (experimental iPadOS 18 port)

Based on the MIT-licensed [Draw reference app](https://github.com/DebelToni/Draw), upstream commit `34e4ed1`. Original copyright is retained in [LICENSE](LICENSE).

This is an **experimental** iPad UI port, not a production note-taking app. The upstream Xcode project targets iOS 26 and includes a private sync/AI stack that is **not** deployed here. This SwiftPM adaptation compiles with `xtool` for iPadOS 18.0+ but has not been validated for feature parity on all devices. `AIClient.swift` contains an intentionally invalid `.example.invalid` endpoint; sync and AI must be separately configured with a trusted backend. Without a private tailnet study-proxy configuration, the AI button explains that it is unavailable and does not send notes to the placeholder endpoint. A separately configured personal proxy supports **purple Pencil handwriting → local OCR preview on the page → explicit Send → streamed answer on the same page → optional Keep**. This is not the upstream AI/sync service and never uploads a whole notebook automatically. Do not use it to store important notes without your own tested backup.

Current UI prototype: dark chrome with warm-white paper, configurable toolbar placement (default left) and hideable controls, notebook-only tabs and previous/next/new-page buttons in the top bar, a single overview button opening a right-side scrollable page overview with multi-select and confirmed deletion (no Deleted pages section), a twice-confirmed Delete notebook action in the document menus, a 44-point top bar with a matching dark status-bar area and a continuous dark side-toolbar corner against the warm-paper bottom edge, a custom grid/wheel ink palette, reserved purple question/context ink, an eraser chooser, a squeeze-only curved custom Pencil palette without a persistent dock (core tools, colors and a configurable circled-plus menu), second-tap stroke-width menus for an already selected pen/highlighter (long-press for Shapes), and both explicit Shape mode and a Pencil end-of-stroke hold-to-snap gesture. Tapping one stroke with Selection opens a contextual menu for copy-as-image, cut, duplicate, delete, resize, style and sharing an image. The custom palette is a visual prototype; actions, alignment and persistence still need individual iPad checks. The optional native-picker comparison mode is not the default. Multi-page deletion and layout also require on-device testing. Deletion removes page/notebook references after confirmation, without a recovery section; a blank page is created if all active pages are removed. Preexisting legacy deleted-page metadata is not purged by this UI change. Shape recognition and gesture interoperability remain experimental; they are not equivalent to Noteful’s multi-object lasso implementation. Ordinary pen strokes are only auto-snapped after a Pencil hold. Patterned-paper controls and pattern rendering are removed (including previews/exports); legacy metadata is kept for compatibility, and new pages are blank.

## Local study tools (experimental)

The notebook options menu offers offline interactive linear/quadratic/sine graphs: parameter value and slider share one compact row, and an icon toggles the values table. Graphs live in atomic page-keyed `InteractiveGraphs` sidecars; an individual legacy graph exports as self-contained interactive HTML. The same menu has an **offline sample of rotatable 3D vectors**. `StudyVisualProtocol.swift` defines a versioned, validated JSON proposal for 2D functions, 3D surfaces/vectors, safe vector diagrams and tables; UIKit renders local accepted/test data with sliders and rotation. Visual sidecars are saved atomically under `InteractiveVisuals`. **Neither type of sidecar is included in DrawPort sync or notebook PDF exports yet**; back up the app container before relying on them.

A labeled **Resources** button on the Home screen opens the matching folder directly; the same library is available from a notebook. Resources mirrors notebook folders and imports PDFs locally without uploading them; existing flat-library PDFs stay Unassigned. Its header and row checkmarks show the exact active folder scope, and out-of-folder files require an explicit session pin. Child folders/older semesters are never included automatically; an Unassigned/root notebook has no automatic PDF scope. Local PDFKit text search highlights matches; scanned PDFs need OCR. **The purple-ink AI trial uses only local OCR text from the current page, not Resources, PDF excerpts, other ink or model-created visual proposals.** On-page AI answers are app-private atomic `StudyAnswers` sidecars and are **not included in notebook sync or PDF exports**; Keep must be tapped to persist one. The AI button in an unconfigured public build still shows a safe unavailable message. Details and outstanding work: [scoped references and visual protocol](docs/study-reference-plan.md), [JSON example](docs/visual-proposal-v1.example.json).

A user-provided opaque Sigma app icon is stored at `branding/AppIcon.png`. The current Linux `xtool` cannot compile an asset catalog; a local private signing stage can add `AppIcon.png` and corresponding Info.plist keys **before signing**. This repository does not contain the private signer, a signed IPA, or account information. The display name and bundle identifier remain DrawPort pending a naming decision.

## Build on Linux

Use Swift 6+ with an iPadOS SDK and [xtool](https://github.com/xtool-org/xtool):

```bash
xtool dev build --ipa
```

This produces an **unsigned** IPA. Update `xtool.yml` to your own stable bundle ID and sign it yourself before installing. Neither Apple credentials nor device pairing records belong in this repository. The iPadOS 18 fallback in `PortablePage.swift` rejects stroke thresholds that only iOS 26 can represent rather than silently changing geometry. A Foundation-only protocol/sidecar self-test lives under `Tests/` and can be compiled on Linux; it is **not** a substitute for visual Pencil/iPad and persistence regression tests. `tools/openrouter-study-test.py` makes one synthetic free-model streaming request with an owner-only local credential. For a personal tailnet trial, `tools/study-ai-server.py` is a **loopback-only** proxy intended behind Tailscale Serve HTTPS: it checks the authenticated owner identity, accepts only the bounded locally recognized purple text after an in-page Send tap, verifies the model is currently listed free and streams plain text. Its provider credential stays on the host; only the HTTPS tailnet endpoint is privately sealed into a signed bundle. No signed bundle, private tailnet URL, key, Tailscale configuration or service unit is published here. Never put a provider key in the IPA.

## Limitations

No bundled/deployed commercial server, sync account, Apple sign-in, signed IPA, provisioning profile, 2FA automation or refresh service. The optional personal proxy requires a separately secured tailnet host; availability and free-model response quality are not guaranteed. Installing an updated IPA without preserving and backing up the existing app container may lose notes; back up before testing updates.
